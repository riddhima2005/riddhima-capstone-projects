# Riddhima Tiwari: Capstone Projects

This repo contains two capstone projects.

## 1. Customer Lifetime Value and Churn Intelligence (`churn-clv/`)

Predicts churn, estimates customer lifetime value, segments customers, and runs an ROI discount simulator.

- Live app: [Churn ROI Simulator](https://churn-roi-simulator-ftbkw29ceahy5qbnqfjx9e.streamlit.app/)
- Details: [churn-clv/README.md](churn-clv/README.md)

## 2. Experimentation and Causal Inference Platform (`experimentation/`)

Checks whether a change really caused a result, using A/B testing, multiple-testing corrections, power analysis, Bayesian testing, matching, difference-in-differences, and DoWhy/EconML.

- Live app: [A/B Test Checker](https://ab-frontend-ojtz.vercel.app)
- Backend API docs: [Swagger](https://ab-backend-15wf.onrender.com/docs)
- Details: [experimentation/README.md](experimentation/README.md)
